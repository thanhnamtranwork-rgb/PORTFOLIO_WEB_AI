# Dữ liệu của MoteLona

Backend hiện chỉ kết nối MongoDB. Dữ liệu khởi tạo nằm trong `../backend/src/main/resources/portfolio-seed.json`; Spring Boot tạo index và nạp dữ liệu cho collection còn trống.

Xem [hướng dẫn lưu trữ MongoDB](../../../../docs/mongodb-data-guide.md) để biết cách dữ liệu đang chạy.
